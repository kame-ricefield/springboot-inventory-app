Spring Boot 在庫管理アプリ

📌 概要
本アプリは、商品在庫を管理するためのWebアプリケーションです。
Spring Bootを用いて開発し、認証機能を含む実務レベルを意識した構成で実装しています。
🎯 作成目的
Web開発案件へのアサインを見据え、実務を意識したアプリ開発を行うため
Spring Boot / MVCアーキテクチャの理解を深めるため
認証・DB連携を含めた一連のWebアプリ開発経験の習得
🛠 使用技術
Java
Spring Boot
Spring Security（ログイン認証）
Thymeleaf
PostgreSQL
HTML / CSS
💡 主な機能
ログイン機能（Spring Securityによる認証）,在庫一覧表示,商品登録
